# Bada Screen

A size repository for large cinema screens in India.

Hyderabad is the full directory: every hall with a published width, including ordinary screens. The other cities are the premium large-format rooms that can be cited — IMAX, Dolby Cinema, PXL, PCX, and the halls next to them. Rectangles are drawn to scale. A missing width stays off the chart.

Sizes come from public reports, including the [Hyderabad Theatres](https://www.hyderabadtheatres.com/specs/) specs table. They can be wrong after a refit.

## Develop

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
